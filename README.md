# 城市与地铁

**在真实城市里，画出你自己的地铁。**

《城市与地铁》是一款在浏览器中游玩的单人地铁规划与城市经营游戏。从第一座车站开始，连接住区、商圈、校园与机场，跨过江河，逐步织出自己的交通网络。城市随年代发展，居民也会根据你的路网重新选择出行方式。

[在线游玩](https://city-and-metro-sojourn.pages.dev) · [源码仓库](https://github.com/Sojourn-1/city-and-metro-sojourn) · [使用许可](./LICENSE.txt)

> **社区版 1.0（by MetroSojourn）**：在原版 3.0 的基础上新增**无锡、苏州、常州**三张大市地图（开局 2010 / 2010 / 2015），并加入同名/异名换乘、站内/出站换乘与升级、预留站、片区分期开放等功能。原版网站：https://city-and-metro.pages.dev；本社区版：https://city-and-metro-sojourn.pages.dev。

## V1.0 社区版 1.0：无锡、苏州与常州

- 这是社区版 1.0（by MetroSojourn）：在原版 3.0 的基础上加入无锡、苏州、常州三张大市地图，原作者 VinsonFung，原版网站 city-and-metro.pages.dev。
- 三市开局年份为无锡 2010、苏州 2010、常州 2015，大事年表与历史任务随之重排：无锡含 2024 年 S1 线开通，苏州含 2023 年 11 号线开通，常州含 2019 年 1 号线与 2021 年 2 号线。
- 片区分期开放：无锡江阴城区与南部 2015、惠山与洛社一带开局即开放、宜兴城区与宜兴东部 2018、雪堰与江阴沿江 2018、丁蜀与宜兴南部 2022、宜兴西部 2024（常州武进、天宁永久锁定）；苏州吴江 2012、昆山 2013、常熟与张家港 2017–2019、太仓 2020–2022；常州金坛 2020、溧阳 2024；苏州图含无锡新吴区（2020）。任务不会落在未开放片区。
- 换乘：车站相距 100–300 m 且线路不同会弹窗询问站内 / 出站 / 不换乘；站内换乘按 1 座车站计、出站各算 1 座，地图上用不同颜色标记。已开通的车站只能升级换乘方式（不换乘→出站→站内），升级写入建设草案、确认建设后生效，升级为站内换乘需另付车站建设费的十分之一。
- 同名换乘只显示一个站名、两站共用一个名字（任一面板改名都会同步），异名换乘各显示各的站名；不换乘时不可选择同名/异名。预留站造价与维护按三分之一计，开通前不停靠、灰色图标，补差价开通。
- 在无锡硕放机场、鹅湖（对苏州）与马山、雪堰（对常州）增设口岸：接通后可乘地铁过境、切换到对岸并查看对岸线网，且不另收跨境附加费。同时并入原版 3.0 的南京、迈阿密地图、任务待办、简洁/专业两档信息、预测与接管铁路改进等更新。
